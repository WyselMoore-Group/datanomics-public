# Citation Information

This page is the canonical citation record for the founding research. The

## Primary Citation

Wysel, M. (2023). *Data Sharing Ecosystems and the Creation of Value
from Data*. PhD thesis, University of New England. Australian Government
Research Training Program Scholarship.

## Thesis Chapters

The thesis is a thesis by publication. The works comprising it are:

- How Platforms Create Value from Agricultural Data
- How to Value Data: Uniting Economic and Information Theory to Create a
  Value Framework for Data
- Profiting from Data
- Take My Data… Please: How Data Sharing Ecosystems Make Oversharing
  Rational
- AgTech, Agricultural Data and Market Failure: Avoiding a Tragedy of the
  (Data) Commons
